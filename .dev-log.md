### This file is just to capture the thought process during development

I'm trying to install [pytorch-geometric](https://pytorch-geometric.readthedocs.io/en/latest/) which obviously relies on `pytorch`.

However, due to `PEP 668` I use virtual environments instead.

For ROCm at least I saw 6 gb download, omg!

So I found [uv](https://docs.astral.sh/uv/) which (quoting from gemini results) makes a python package cache usually at `~/.cache/uv` on Linux and allows virtual environments to access it.

Which luckily for me saves me from installing pytorch a billion times.
